## About

Most of the projects here started because I needed them myself. A repo I couldn't understand, a diagram I didn't want to draw by hand, a bit of Python I wanted to run without opening an editor. So I build the tool, put it online, and move on to the next idea.

These days I work mostly in TypeScript and React, add AI APIs to my side projects, and practice DSA and system design when I get time. If you want to build something together, send me a message.
